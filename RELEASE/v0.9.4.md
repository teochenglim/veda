# RELEASE v0.9.4 — Patch

**Status:** ready (toolchain floor bump + dependency refresh, no behavior change)
**Theme:** clear the Go 1.27.2 `crypto/x509` advisory and refresh Go modules.

## Release notes

### Security
- `go.mod` now requires **Go 1.27.3** (was 1.27.2). `govulncheck` flagged a
  standard-library finding in `crypto/x509` (found in go1.27.2, fixed in
  go1.27.3), reachable through veda's TLS client paths.
- No veda source changes were needed.

### Dependencies
- All modules bumped to latest via `go get -u ./...` + `go mod tidy`,
  including `modernc.org/sqlite` v1.58.0 → v1.61.0, `modernc.org/libc`
  v1.75.6 → v1.79.1, and the `golang.org/x/*` modules (crypto, net, sys,
  sync, text, time, term).

### Notes
- Release/CI workflows use `GO_VERSION: '1.27'`, which `setup-go` resolves to
  the latest 1.27.x, so they pick up the patched toolchain too.
- Anyone building from source needs Go ≥ 1.27.3.

## Verification
`make vet test` green on go1.27.3. Re-run `govulncheck ./...` (security workflow) to confirm the advisory clears.

## No AC changes
All v0.1–v0.9.3 acceptance criteria and their tests are unchanged.
