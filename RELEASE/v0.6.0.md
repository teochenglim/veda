# RELEASE v0.6.0 — Advanced eval harness (paid, the moat)

**Status:** implemented (tests enforce the ACs below)
**Theme:** measure recall the way users experience it — and prove distillation didn't make things up.

## Release notes

### Added
- **Scenario format**: fixture files (single scenario or `{"scenarios": […]}`)
  describing seed memories and/or fixture conversations, plus recall cases
  (`query`, `top_k`, `min_confidence`, `semantic`, `expect_contains`,
  `expect_not_contains`).
- **`veda eval -f suite.json`**: runs scenarios against a **throwaway
  store** — the user's real `~/.veda` is never opened — and prints PASS/FAIL
  per scenario with failing-case reasons. Exits non-zero when anything
  fails (CI-friendly). `--report out.json` writes the machine-readable run.
- **Interference detection**: an `interference` block ingests disruptor
  memories and re-scores guard cases; a pass-rate drop beyond `max_drop`
  fails the scenario — the "learning B wiped out A" detector.
- **Faithfulness scoring**: memories distilled from fixture turns are scored
  by token attribution against those turns; score < 0.3 flags an invention
  and fails the scenario.
- **Paid tier — cross-install benchmarks**: `--upload-url` posts anonymized
  aggregates (scenario name, score, pass, case count — never content) to
  the benchmark backend; `402` surfaces the paid-gate message. Backend
  ships in a separate repository.
- Fixture `turns` flow through the real cheap gate; with the user's LLM
  key configured they distill through the real prompt path.

## Acceptance criteria

Every AC is a named Go test (`make test`).

| # | Acceptance criterion | Test |
|---|---|---|
| AC1 | Scenario files load (single + suite); malformed ones fail with actionable, scenario-naming errors | `eval.TestAC1_ScenarioLoading` |
| AC2 | Seeding + recall scoring: pass/fail cases and aggregate score are correct | `eval.TestAC2_RunScoresRecallCases` |
| AC3 | Interference detection flags real degradation and passes benign disruption | `eval.TestAC3_InterferenceDetection` |
| AC4 | Faithfulness scoring flags memories not attributable to source turns | `eval.TestAC4_FaithfulnessFlagsInventions` |
| AC5 | Running eval never mutates the user's real store | `eval.TestAC5_EvalIsIsolatedFromRealStore` |
| AC6 | Benchmark upload posts aggregates only and honors the 402 paid gate | `eval.TestAC6_UploadPaidGate` |
