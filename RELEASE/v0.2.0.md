# RELEASE v0.2.0 — Semantic recall

**Status:** implemented (tests enforce the ACs below)
**Theme:** recall that understands meaning, not just keywords.

## Release notes

### Added
- **Vector search alongside FTS5.** Every memory can carry an embedding
  (`memories_vec` table, added lazily — a v0.1 database upgrades with no
  migration step; the worker backfills vectors on its next pass).
- **Hybrid ranking by weighted reciprocal-rank fusion**: FTS5 bm25 ranking
  (weight 0.6) fused with embedding cosine similarity (weight 0.4). Exact
  keyword matches keep their top spot; semantic neighbors get appended and
  re-ranked.
- **`recall` gains `semantic: true`** for pure embedding-ordered results;
  the default stays hybrid.
- **Embeddings via any OpenAI-compatible `/embeddings` endpoint**
  (`[embed]` in `config.toml`). A localhost URL (Ollama, LM Studio) keeps
  embeddings entirely on the machine. Default config: `enabled = false`.
- **Worker backfill**: each pipeline pass embeds up to N memories missing
  vectors; an embedder outage is logged and skipped, never fatal.
- Digest tab + telemetry stats gain an `embedded` count (vector coverage).

### Changed
- `recall` ranking blends keyword and semantic signals (was keyword-only).

## Acceptance criteria

Every AC is a named Go test (`make test`).

| # | Acceptance criterion | Test |
|---|---|---|
| AC1 | A semantic query sharing no keywords with a memory still recalls it | `store.TestAC1_SemanticParaphraseRecall` |
| AC2 | Hybrid ranking never ranks the exact-keyword FTS winner below a semantic-only neighbor | `store.TestAC2_ExactKeywordStaysTop` |
| AC3 | Embedding-provider failure (or no embedder configured) degrades to keyword-only recall, never an error | `store.TestAC3_EmbedderFailureDegradesToFTS`, `worker.TestWorkerBackfillEmbedderFailureIsBestEffort` |
| AC4 | Embeddings go to exactly one destination — the configured BaseURL — and nothing else | `embed.TestAC4_SingleConfiguredDestination` |

Plus supporting tests: `embed.TestClientErrorPropagates`, `embed.TestCosine`,
`store.TestVectorBookkeeping`, `worker.TestWorkerBackfillsEmbeddings`.
