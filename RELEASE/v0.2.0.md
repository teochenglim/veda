# RELEASE v0.2.0 — Semantic recall (planned)

**Theme:** recall that understands meaning, not just keywords.

## Release notes (draft)

### Added
- Vector search alongside FTS5: local embeddings (configurable provider;
  on-device model supported) with a hybrid ranker `bm25 ⊕ cosine`.
- `recall` gains optional `semantic: true` parameter; default stays hybrid.
- Migration on first run: backfills the embedding table for existing memories.

### Changed
- Recall ranking now blends FTS5 bm25 with embedding cosine similarity.

### Fixed
- (fill from v0.1 feedback — every recall failure reported at launch gets a
  log entry in the eval scenario draft, per the PRD posting rules)

## Acceptance criteria (draft)

| # | Criterion | Test (to add) |
|---|---|---|
| AC1 | Semantic query ("things that keep me up at night") recalls "caffeine after 2pm" memory | `recall` semantic test |
| AC2 | Hybrid ranking never ranks below pure-FTS for exact keyword queries | hybrid ranker test |
| AC3 | Embedding provider failure degrades to FTS5-only, never errors | fallback test |
| AC4 | Embeddings never leave the machine when a local provider is configured | provider boundary test |

## Out of scope
Cross-agent conflict resolution (v0.3), hosted sync (v0.4).
