# RELEASE v0.9.5 — Patch

**Status:** ready (toolchain floor bump, no behavior change)
**Theme:** clear the Go 1.27.3 `net/http` advisory GO-2026-6859.

## Release notes

### Security
- `go.mod` now requires **Go 1.27.4** (was 1.27.3). `govulncheck` flagged
  GO-2026-6859 ("HTTP/1 server crash due to MaxBytesReader header race in
  net/http", found in go1.27.3, fixed in go1.27.4), reachable through the
  loopback UI server, the telemetry/eval HTTP clients and the MCP SDK.
- No veda source changes were needed.

### Notes
- The security workflow uses `go-version-file: go.mod` with `GOTOOLCHAIN: local`,
  so bumping `go.mod` is what makes CI install the patched toolchain.
- Release/CI workflows use `GO_VERSION: '1.27'`, which `setup-go` resolves to
  the latest 1.27.x.
- Anyone building from source needs Go ≥ 1.27.4.

## Verification
`make vet test` green on go1.27.4. Re-run `govulncheck ./...` (security workflow) to confirm the advisory clears.

## No AC changes
All v0.1–v0.9.4 acceptance criteria and their tests are unchanged.
