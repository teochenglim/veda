# RELEASE v0.4.0 — Hosted sync (planned, paid)

**Theme:** your memory, on every machine you own.

## Release notes (draft)

### Added
- End-to-end encrypted sync (keys never leave devices; the server stores
  ciphertext only) backed by Supabase — per PRD §3, hosted sync not telemetry.
- `veda sync status / push / pull`, background merge on `serve`.
- Last-writer-wins per memory id with a tombstone set for cross-device deletes.
- Billing hooks: free tier stays local-only; sync is the first paid feature
  ($5–15/mo per pricing model).

## Acceptance criteria (draft)

| # | Criterion | Test (to add) |
|---|---|---|
| AC1 | Server-side storage of a pulled sync bundle contains no plaintext | ciphertext-only test |
| AC2 | Two devices converging on independent edits reach identical state | CRDT/merge test |
| AC3 | Deleting on device A removes the memory on device B (tombstones) | tombstone test |
| AC4 | Sync fully disabled ⇒ zero network calls | network-boundary test |

## Risks
- Supabase free tier auto-pauses after one week of inactivity — sync traffic
  is expected to be sparse; monitor and upgrade to Pro before launch.
