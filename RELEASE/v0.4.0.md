# RELEASE v0.4.0 — Hosted sync (first paid tier)

**Status:** implemented (client side; tests enforce the ACs below)
**Theme:** your memory, on every machine you own.

## Release notes

### Added
- **End-to-end encrypted sync**: bundles sealed with XSalsa20-Poly1305,
  key derived (scrypt) from a sync passphrase that lives only in your
  environment (`VEDA_SYNC_PASSPHRASE`). The server stores opaque
  ciphertext — memories are never readable server-side.
- **`veda sync status | push | pull`**; `veda serve` runs a background
  merge loop every interval when sync is enabled.
- **Last-writer-wins merge** per memory id with a **tombstone** set for
  cross-device deletes; supersession status syncs as row data, so conflict
  resolutions propagate.
- **Change-log watermark** (sequence-based, not wall-clock): same-second
  writes after a push are never missed; pulled rows never re-propagate.
- **Paid-tier billing hook**: backend `402` surfaces as
  `ErrPaymentRequired` with a friendly message. Local features stay free
  forever.
- **In-place upgrade**: `tombstones`, `change_log`, `sync_state` tables are
  created on open; existing rows are backfilled so the first push carries
  the whole store.
- Digest-quality sync bookkeeping: `veda sync status` shows device id,
  pending memories/tombstones, push cursor.

### Changed
- `memories.deleted` now round-trips through export/JSON (was omitted).
- Sync is **off by default**; config lives in `[sync]` (`enabled`, `url`,
  `token_env`, `passphrase_env`, `interval_minutes`).

## Acceptance criteria

Every AC is a named Go test (`make test`).

| # | Acceptance criterion | Test |
|---|---|---|
| AC1 | Server-side storage of a pushed bundle contains no plaintext | `syncengine.TestAC1_ServerSeesNoPlaintext` |
| AC2 | Two devices converging on independent edits reach identical state | `syncengine.TestAC2_TwoDevicesConverge` |
| AC3 | Deleting on device A removes the memory on device B (tombstones) | `syncengine.TestAC3_TombstoneRemovesOnOtherDevice` |
| AC4 | Sync fully disabled ⇒ zero network calls | `syncengine.TestAC4_DisabledSyncNeverTouchesNetwork` |

Supporting tests: wrong-passphrase rejection, order-independent merge,
tombstone-vs-newer-edit LWW, 402 payment gate, passphrase-never-persisted.
