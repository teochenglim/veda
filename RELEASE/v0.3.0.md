# RELEASE v0.3.0 — Cross-agent conflict resolution

**Status:** implemented (tests enforce the ACs below)
**Theme:** when Cursor and Claude disagree about you, Veda mediates.

## Release notes

### Added
- **Auto-supersession on write**: a new memory that contradicts an active one
  marks the older entry `superseded` (not deleted) instead of silently
  keeping both. Detection is heuristic and instant — slot extraction
  (residence, employer, tool, role) plus a negation rule — no LLM call.
- **`conflicts` table + Conflicts tab** in the review UI: every detected pair
  (old strikethrough → new) with **Prefer new / Prefer old / Keep both**
  actions; every resolution is audited on both memories.
- **Recall excludes superseded memories** on all paths (keyword, hybrid,
  semantic): a conflict can never answer twice.
- **`list` gains `include_superseded: true`**; the All tab accepts
  `?superseded=1`.
- **In-place upgrade**: v0.1/v0.2 databases get the `status` /
  `superseded_by` columns and `conflicts` table via migration on open; all
  existing rows default to `active`.
- Digest/stats gain a `superseded` count.

### Changed
- `remember` may now supersede an older memory — the audit log records a
  `supersede` entry with the detection reason.

## Acceptance criteria

Every AC is a named Go test (`make test`).

| # | Acceptance criterion | Test |
|---|---|---|
| AC1 | "User lives in Singapore" then "User moved to Tokyo" ⇒ old memory superseded, not duplicated | `store.TestAC1_SupersedeOnContradiction`, `conflict.TestDetect_SlotChange/residence_move` |
| AC2 | Recall never returns both sides of a conflict by default | `store.TestAC2_RecallExcludesSuperseded`, `mcpserver.TestAC4_ListIncludeSuperseded` |
| AC3 | Keep-both decision is honored and audited | `store.TestAC3_ResolveKeepBoth`, `ui.TestAC3_ConflictsTabAndResolutions` |
| AC4 | `list include_superseded: true` reveals both sides with `superseded_by` markers | `mcpserver.TestAC4_ListIncludeSuperseded` |
| AC5 | v0.2 database upgrades in place; detection works on migrated rows | `store.TestAC5_MigrationFromV02Schema` |

Supporting tests: `conflict.TestAnalyze_SlotExtraction`,
`store.TestResolvePreferOld` (direction swap + invalid resolution rejection).
