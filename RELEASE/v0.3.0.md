# RELEASE v0.3.0 — Cross-agent conflict resolution (planned)

**Theme:** when Cursor and Claude disagree about you, Veda mediates.

## Release notes (draft)

### Added
- Contradiction detection on write: a new memory that conflicts with an
  existing one (same subject, different predicate) marks the older entry
  `superseded` instead of silently keeping both.
- Recall returns the most recent non-superseded memory per subject by default.
- UI: Conflicts section in the Pending tab showing both sides with
  keep-both / prefer-new / prefer-old actions.

### Changed
- `list` accepts `include_superseded: true`.
